# Congruence of Negative Integers in Python

Given a number `-3 mod 7`, which number is it congruent to?

**Answer:** 4

**Why:** Because we need to keep adding q, which is the mod, until we find a number that is actually in the set. In this case, something in the set `{0,1,2,3,4,5,6}`.

# Additive Inverses in Modular Arithmetic

Additive inverse of a number `x` is another no `y` s.t `x + y = 0`

# q-1 is congruent to -1

Given q = 5, then `−1 ≡ 4`, i.e. `-1 + 5 = 4`

# q-k is congruent to -k

Assuming q > k, then `−k ≡ q − k (mod q)`

### Example

Given q = 11 and k = -3:
- `−3 ≡ 11 − 3 (mod 11) = 8`
