# ZK-SNARKs from First Principles

My notes while working through the RareSkills course of the same name.

The course is split into chunks, and this repo mirrors that: one markdown file per chunk, named
`chunkN:TOPIC.md`. Each file is my own restatement of the material, not a copy of the course: the
definition in my own words, the examples I worked by hand, and the "wait, why?" notes where
something did not click the first time.

## How to read a chunk file

Every chunk file follows the same shape:

- **What it is**: the definition, written plainly.
- **Examples**: small concrete cases, including the ones that fail.
- **NOTE blocks**: the edge cases and traps, usually the thing I got wrong first.

## Conventions

- Notation stays in unicode (`⊆`, `∈`, `∉`) rather than LaTeX, so the files stay readable as plain text.
